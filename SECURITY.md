# Security policy

## Supported version

Only the current `main` branch and the corresponding GitHub Pages deployment receive security fixes.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use the repository's [private vulnerability reporting form](https://github.com/buicongnguyen/SystemDesign/security/advisories/new). Include the affected URL or file, reproduction steps, impact, and any suggested mitigation.

If private vulnerability reporting is unavailable, open a public issue containing no vulnerability details and ask the maintainer to establish a private contact channel.

This is a static educational site. Content inaccuracies and ordinary broken links are not security vulnerabilities; use the issue templates for those reports.
